Tienda_adso es un desarrollo que consistente en una aplicación backend y frontend orientada a la gestión de productos, inventario, usuarios y ventas para una tienda local. Construida sobre Python 3.14 y administrada dentro de un entorno virtual (.venv), la solución integra herramientas asíncronas y de validación de datos como anyio y pydantic, utilidades para interfaces de línea de comandos mediante click y colorama, y gestión de seguridad con certifi. Su estructura modular incluye configuración de variables de entorno mediante .env, control de versiones con Git y un diseño concebido para facilitar el despliegue, la personalización de reglas de negocio y el seguimiento centralizado del comercio.
